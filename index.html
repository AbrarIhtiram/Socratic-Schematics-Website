About the Program

What is FRC?

The FIRST Robotics Competition (FRC) is an international high school robotics program where teams design, build, and program industrial-sized robots to compete in a new game every year. Beyond robots, FRC emphasizes teamwork, engineering, creativity, and real-world problem solving.
